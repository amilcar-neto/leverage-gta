- `png/`: o alvo visual. O revisor compara os prints do Foundry com estes.
- `html/`: as mesmas telas como HTML estático. Abra no navegador e use o inspetor para medir tamanhos e cores exatos.
- `source/`: os arquivos originais do design (formato `.dc.html` do Claude Design, com dados de exemplo e a lógica
  de estados em JavaScript, ex.: a constante `GEOM` das formas dos dados e a função `die()` dos estados). Leia para
  tirar dúvidas de comportamento; não copie a estrutura de template, que é de outra ferramenta.
- Os dados de exemplo (Rosa Delgado, Jobs, Assets) são fictícios e servem para o compêndio de exemplo (T-902).
